# وصلة — واجهة وخادم الخدمات الجامعية

تطبيق عربي باتجاه RTL مبني باستخدام React وVite، مع API في Node.js وقاعدة بيانات SQLite محلية. يدعم موجز المشروع طلبات الخدمات ومتابعة حالتها وإدارة العروض والملفات الشخصية. لا يتضمن الدفع الإلكتروني أو التقييمات أو المحادثة.

تستخدم الواجهة `Alexandria` للعناوين الكبيرة و`IBM Plex Sans Arabic` لبقية العناصر، مع `Noto Sans Arabic` كخط بديل. الخطان متاحان عبر Google Fonts بترخيص مفتوح.

## المتطلبات والتشغيل

- Node.js 24 أو أحدث (لأن الخادم يستخدم `node:sqlite` المدمجة).
- شغّل `npm install` مرة واحدة.
- شغّل `npm run dev` لتشغيل API على `http://127.0.0.1:3001` وواجهة Vite على `http://127.0.0.1:5173`.
- شغّل `npm run build` لإنشاء نسخة الإنتاج داخل `dist/`.
- بعد البناء، شغّل `npm run server` لتقديم الواجهة وAPI معًا من المنفذ 3001.

تُنشأ قاعدة البيانات تلقائيًا في `server/data/wasla.sqlite` عند أول تشغيل. ويمكن تحديد مسار مختلف باستخدام `WASLA_DB_PATH`.

## حسابات العرض المحلية

في بيئة التطوير، ينشئ الخادم حساب طالب وأربعة حسابات لمقدمي الخدمات عند تهيئة قاعدة بيانات جديدة. استخدم كلمة المرور `WaslaDemo2026!` مع أي من الحسابات التالية:

- الطالب: `student@wasla.local`
- مقدم الطباعة: `print@wasla.local`
- مقدم صيانة الأجهزة: `repair@wasla.local`
- مقدم الدروس: `tutor@wasla.local`
- مقدم التصميم: `design@wasla.local`

التسجيل العام يقبل حساب طالب أو مقدم خدمة فقط. لإنشاء حساب مسؤول محلي، عيّن `WASLA_ADMIN_EMAIL` و`WASLA_ADMIN_PASSWORD` (12 حرفًا على الأقل) قبل أول تشغيل. للمنافذ والاستضافة يمكن تحديد `PORT` و`HOST`، وعلى النشر إعداد `WASLA_ALLOWED_ORIGINS` بقائمة مصادر الواجهة المسموح بها مفصولة بفواصل.

## واجهات API

- `POST /api/auth/register` و`POST /api/auth/login` و`POST /api/auth/logout`
- `GET /api/auth/me` و`GET /api/bootstrap`
- `PATCH /api/profile`
- `POST /api/offers` و`PATCH /api/offers/:id`
- `POST /api/requests` و`PATCH /api/requests/:publicId/status`
- `GET /api/admin/summary` للمسؤول
- `GET /api/health` لفحص جاهزية الخادم

الجلسات تُخزن على الخادم، ويُرسل معرّفها في ملف ارتباط `HttpOnly` مع `SameSite=Lax`. تُحفظ كلمات المرور باستخدام `scrypt`، وتُحفظ الطلبات وانتقالات حالاتها في SQLite. يسمح الخادم بتغييرات الحالة التالية: جديد ← قبول أو اعتذار، مقبول ← بدء التنفيذ، قيد التنفيذ ← مكتمل.

## تنظيم المشروع

- `src/`: واجهة React وربطها مع API.
- `server/index.js`: الخادم، المصادقة، الصلاحيات وقاعدة SQLite.
- `scripts/dev.js`: يشغّل خادم التطوير والواجهة معًا.
- `vite.config.js`: يمرر طلبات `/api` إلى الخادم أثناء التطوير.

هذا إصدار أولي محلي؛ لا يتضمن نشرًا أو إعداد خادم سحابي، كما أن حسابات العرض وكلمة مرورها مخصصة للتطوير فقط.
